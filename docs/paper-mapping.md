## 已知缺口（誠實記錄）

1. **AYP 紀錄（紙本 p15、p91–101，共 12 頁）**：數位版暫無獎勵計劃分科紀錄頁。AYP 另有專用紀錄冊，
   本冊只在制服圖例提及；是否補頁待用戶決定。
2. **全文獎章（領導才／服務／先修／宗教／社區）**：紙本佔 11 頁全文，數位版只記一行完成紀錄。
   如要全文，需擴充綱要（現綱要只收名稱）。
3. **途徑圖（紙本 p11）**：總領袖獎章之路徑圖暫無數位版。
4. **紀錄專欄**：露營晚數、遠足里數、服務時數等專欄暫用通用活動行代替。

## 核對方法

```bash
pip install --break-system-packages pypdf
python3 -c "
from pypdf import PdfReader
r = PdfReader('scout-record-book_20260829.pdf')
print(len(r.pages))  # 應為 111
print((r.pages[60].extract_text() or '')[:60])  # 紙本 p60 應為總領袖獎章開卷
"
```

> PDF 版權屬香港童軍總會，本倉庫只引用頁碼及欄名作對照，不收錄 PDF 全文或掃描圖。
> 官方徽章裁圖僅作紀錄冊內識別之用，版權同屬總會。
