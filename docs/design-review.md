# Design Review — 視覺與互動巡檢紀錄

本文件記錄 `SCOUTBOOK` 在 `390×844`（手機）、`768×1024`（平板）及 `1440×900`（桌面）三個標準斷點，以及 `A4 @media print` 列印模式下的設計規範與巡檢結果（對齊真理倉 `design-review` 技能要求）。

> 誠實聲明：用戶已確認未能實測三個寬度；本倉亦無瀏覽器／真機。因此本文件只記錄**色板公式（已用程式計算）＋機器可驗契約**；真機手勢、相機掃碼、列印預覽仍須實測，未完成前不作「全綠」宣稱，對外一律標示「機器驗證通過，真機待測」。

## 視覺基準（Visual Baseline）

以下色值為 `web/src/styles.css` 實裝值（2026-11-05 核對；如改動必須同步重算）：

- **布面主色（Scout Green）**：`#143b28`（封面 `--cover-bg`）→ `#08180f`（深底 `--cover-bg-deep`）；內頁綠墨 `#1c5236`（`--scout-green`）；燙金 `#e3c07a`（`--foil`）／`#f6e6bb`（`--foil-soft`）作封面文字、框線與點綴。童軍支部的識別色就是綠，因此綠是主色，金是墨色之一。
- **綠金對比陷阱處理**（2026-11-05 以 WCAG 公式實算，非估計）：
  - 燙金字 `#f6e6bb` 配深綠 `#143b28` ＝ `10.06:1` ✅ —— **金字只准上深綠**。
  - 燙金 `#e3c07a` 配深底 `#08180f` ＝ `10.53:1` ✅。
  - 象牙 `#f7f2e7` 配深綠 `#143b28` ＝ `11.16:1` ✅。
  - 綠墨標題 `#1c5236` 配象牙紙 `#f7f2e7` ＝ `8.14:1` ✅；主墨 `#1e1a14` 配象牙紙 ＝ `15.51:1` ✅；輔助字 `#4a4337` ＝ `8.75:1` ✅；第三層字 `#6a6152` ＝ `5.46:1` ✅；手寫綠墨／蓋印 `#124a26` ＝ `9.25:1` ✅（v1.1.0 起藍墨轉綠；真正錯誤另用 `--danger` 紅 `#a62626`）。
  - 深炭字 `#1a1206` 配燙金底 `#e3c07a` ＝ `10.67:1` ✅ —— **金底按鈕一律用深炭字**。
  - 白字 `#ffffff` 配金黃 `#e6a800` ＝ `2.11:1` ❌ —— **禁止白字配金黃**，證明設計上不可用。
  - `tests/ui_contracts.test.mjs` 會以同公式鎖定，任何配色改動必須重算重驗。
- **紙本內頁（Ivory Paper）**：`#f7f2e7`（紙底）、`#efe8d6`（次底）、`#1e1a14`（深墨）、`#4a4337`（輔助字）、`#6a6152`（第三層字）。
- **字體階層**：標題用襯線體（`Noto Serif TC` / `Songti TC`）呈現正式紀錄冊感；表格與輸入欄用無襯線體（`Noto Sans TC` / `PingFang HK`）；編號、日期、容量計用等寬數字。
- **全螢幕實體書**：封面 `100dvh` 布紋 + 燙金框 + 持有人銘牌 + 獎章章位；內頁為 A4 比例紙張，無卡片框線與陰影。
- **中英完全分離**：頂欄一鍵 `中文 / EN`；`html[data-lang="zh"]` 隱藏內頁英文副標，英文模式全英；不以「中文 English」並排塞入同一表格。
